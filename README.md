# Parking Manager — Telegram bot

Личный Telegram-бот для учёта аренды парковочных мест.

## Что умеет
- Импортирует исходные места из `tenants_import.csv`.
- Хранит арендаторов, автомобиль, тариф и день оплаты.
- Записывает фактические поступления и период предоплаты.
- Считает текущие неоплаченные места и показывает оплаты на сегодня.
- Формирует месячный отчёт по фактическим платежам, зарегистрированным в боте.
- Отправляет ежедневное напоминание в 12:00 и месячный отчёт в 12:05 по Москве.

## Важно о первоначальном импорте
В исходной таблице есть статусы по месяцам, но нет дат и сумм фактических транзакций. Они импортируются как исходные статусы/оплаченный период. Они **не** добавляются в финансовые отчёты как денежные поступления. Поэтому отчёты по фактическим поступлениям будут полными с момента регистрации оплат в боте.

## Переменные окружения Railway
- `BOT_TOKEN` — новый токен от BotFather (никогда не коммитить в GitHub).
- `ADMIN_CHAT_ID` — ваш числовой Telegram ID.
- `DB_PATH` — `/data/parking.sqlite3` (при подключённом Railway Volume, см. ниже).
- `IMPORT_FILE` — `tenants_import.csv`.

## Деплой
1. Создать приватный GitHub-репозиторий и загрузить все файлы из этой папки в корень репозитория.
2. В Railway создать сервис из GitHub-репозитория.
3. В Variables добавить `BOT_TOKEN`, `ADMIN_CHAT_ID`, `DB_PATH=/data/parking.sqlite3`.
4. Подключить Railway Volume к сервису с mount path `/data`, чтобы SQLite-база сохранялась при перезапусках и деплоях.
5. Убедиться, что сервис запущен как Worker; команда запуска: `python bot.py`.

## Первый запуск
1. Откройте бота в Telegram и отправьте `/id` — он покажет числовой Telegram ID.
2. Добавьте этот ID в Railway как `ADMIN_CHAT_ID`, затем перезапустите сервис.
3. Отправьте `/start`.

## Команды
- `/places` — список мест.
- `/pay 1211 3` — принять оплату по стандартному тарифу за 3 месяца.
- `/pay 1211 3 90000` — записать указанную сумму за 3 месяца.
- `/debts` — места, не оплаченные за текущий месяц.
- `/today` — оплаты, срок которых наступает сегодня.
- `/report 2026-11` — поступления за месяц.
- `/history 1211` — история платежей по месту.
- `/add 3001 | Иван | BMW | 30000 | 15` — добавить место.
- `/edit 1211 32000` — изменить месячную стоимость.

Все даты и напоминания — по часовому поясу Europe/Moscow.
